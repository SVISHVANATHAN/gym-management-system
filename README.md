# 🏋️ Gym Management System

A full-stack Gym Management System built to simplify gym administration, member management, membership plans, and payment tracking.

## 🚀 Features

### Admin Management

- Admin registration and login
- JWT-based authentication
- Protected API routes
- Password hashing using bcrypt

### Member Management

- Create new members
- View all members
- View individual member details
- Update member information
- Delete member records
- Input validation using Zod

### Membership Management

- Create and manage membership plans
- View available membership plans
- Update membership plan details
- Delete membership plans

### Payment Management

- Manage membership payments
- Track payment records

### Frontend

- Responsive dashboard
- Login and registration pages
- Member management interface
- Membership plan interface
- Payment management interface

## 🛠️ Technologies Used

### Frontend

- React.js
